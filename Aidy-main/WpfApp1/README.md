# Aidy Voice ID + Whisper

Объединённая версия: функции `Aidy-voice-id-beta_2-` и текущие изменения из `Aidy-main`, включая незакоммиченные исправления.

## Запуск

Запустите `bin/Release/net8.0-windows/WpfApp1.exe` или `Start-Aidy.ps1`.
Для этой папки подготовлено отдельное окружение `.venv`; зависимости старой `Aidy-main` не изменялись.
Whisper и Voice ID после подготовки моделей работают локально, без загрузок при обычном запуске.

Чистая установка: Python 3.10 x64, .NET 8 SDK, затем `powershell -ExecutionPolicy Bypass -File .\setup.ps1`.
Скрипт устанавливает закреплённые зависимости и подготавливает обе модели. Для существующего кэша можно использовать `-SkipModelDownload`.

## Что сохранено

- Whisper tiny.en, активация Aidy/Hey, обработка команды после активации, короткий голосовой ответ.
- Буферизация микрофона, восстановление после потери аудио, фильтрация шума, PTT и исправления задержек.
- Точный выбор приложений, подтверждения, отрицания, переключение окон, таймеры и учебный режим.
- Voice ID, регистрация пяти фраз, профили Admin/User/Guest, управление профилями и выдача доступа.
- Пользовательские режимы, команды мыши, выбор предпочтительных приложений и новые настройки.
- Новый интерфейс/эмблема/заставка, текущая радиальная анимация и док-панель по краям экрана.

Распознавание речи остаётся английским. Перед использованием Voice ID зарегистрируйте свой голос через настройки.

## Разработка

```
.\.venv\Scripts\python.exe -m unittest discover -s PythonCore/aidy/tests -q
dotnet build WpfApp1.csproj -c Release
.\.venv\Scripts\python.exe scripts/verify_speech.py
.\.venv\Scripts\python.exe scripts/verify_two_stage.py
.\.venv\Scripts\python.exe scripts/verify_voice_id.py
```

Готовая проверенная сборка находится в `bin/Release`. Старый установщик из исходного архива не обновлялся: для этой версии используйте готовый EXE или `setup.ps1`. Перед выпуском нового установщика нужно отдельно подготовить его встроенное Python-окружение с новыми зависимостями и моделями.
